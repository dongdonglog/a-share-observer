# 席位跟随操作手册

本文是 **README 第五节结论的落地版**：把"统计优势"翻译成可执行规则。

所有数字来自 2026-01-05 ~ 2026-09-28（180 个交易日），口径为
**可执行口径**：剔除次日涨停（买不进）的样本，扣除 0.40% 往返成本
（印花税+佣金+过户费 0.10%、双边滑点 0.30%），并按 `billboard_uniq`
去重视图统计（避免同股多上榜原因被重复计数）。

---

## 一、核心规则（三条，按重要性排序）

### 规则 1：只跟高胜率席位

**门槛：席位胜率（东财 `RISE_PROBABILITY_3DAY`）≥ 60，建议 ≥ 70。**

| 阈值 | 可买样本 | D1 净 | **D5 净** |
|---|---|---|---|
| ≥50 | 9,146 | **-0.70%** | **-0.50%** |
| ≥55 | 4,284 | -0.11% | +1.73% |
| **≥60** | 3,363 | +0.17% | **+2.71%** |
| ≥65 | 2,666 | +0.50% | +4.01% |
| **≥70** | 1,982 | +0.89% | **+5.82%** |
| ≥80 | 1,593 | +1.23% | +7.28% |

**50% 是亏的**（D1 -0.70%、D5 -0.50%）。它那些"好看"的原始收益
几乎全部来自买不进的次日涨停股。

### 规则 2：优先跟"低频"席位

**活跃度 = 该席位在过去 60 个交易日的上榜次数。优先 ≤2 次。**

| 组合（胜率 ≥60）| 可买样本 | D1 净 | **D5 净** | 胜率 |
|---|---|---|---|---|
| 基准 | 3,363 | +0.17% | +2.71% | 55.5% |
| **+ 低频（≤2 次）** | 1,899 | +0.82% | **+5.40%** | **60.8%** |
| + 中频（3-9 次）| 848 | -0.62% | +0.22% | 48.7% |
| + **高频（≥10 次）** | 616 | -0.72% | **-2.11%** | 48.2% |

**"天天霸榜的知名游资"是反向指标**——它们多是通道/量化资金，
不是选股能力。这一条**独立于胜率**，可以叠加。

> 这个结论解决了一个外部矛盾。一份公开复现发现"上榜次数越多后续超额越差"，
> 与本节"高胜率越好"看似冲突。用本地数据分解后**两者都对**：
> 控制住胜率后活跃度确实单调反向，外部按活跃度排序看到负相关
> （因为高频席位大多是低胜率），本节按胜率排序看到正相关。两个维度可叠加。

### 规则 3：持有到 D5，不要做 D1

**D1 的收益几乎被跳空吃光。** 龙虎榜盘后披露，你只能次日买，
而次日涨停（**27.1%** 的情况）根本买不进——那部分"D1 收益"
统计上归你，实际拿不到：

| 组别 | 占比 | D1 均值 |
|---|---|---|
| 次日涨停（买不进）| **27.1%** | +12.30% |
| 次日未涨停（可买）| 72.9% | +0.66% |

原始口径 D1 +2.14% → 可执行 **D1 净 +0.17%**，**高估 2.90%**。
而 **D5 净 +3.09%**。**D5 是唯一有实际意义的持有期。**

## 二、风险控制（比选股更重要）

### 必须看分布，而不是均值

**≥70% 档（可执行口径）**：

| 期 | 均值 | 中位数 | 5% 分位 | **最差** | 胜率 |
|---|---|---|---|---|---|
| D1 | +2.69% | +2.47% | -5.95% | **-17.39%** | 64.9% |
| D2 | +5.76% | +4.41% | -6.68% | -22.88% | 77.5% |
| D5 | +8.40% | +5.57% | -11.86% | **-96.57%** | 71.1% |
| D10 | +7.06% | +2.32% | -20.45% | -96.47% | 58.4% |
| D20 | +4.99% | **-1.28%** | -30.19% | -97.49% | 47.2% |

**三个关键点：**

1. **D1 的尾部最窄**（最差 -17.39%），D5 起就出现 **-96.57%**
   （踩到退市或连续跌停）。
2. **D20 中位数是 -1.28%**：典型的一笔是亏的，靠个别翻倍股拉平均。
   **这种分布下重仓长持非常危险**——也解释了为什么短线必须快进快出。
3. **门槛的价值一半在收益、一半在避免踩雷**（≥50% 档的 D1 最差是
   -88.77%，≥70% 档只有 -17.39%）。

### 仓位建议（基于上述分布推导，非投资建议）

- **单票上限**：存在 -96% 尾部，任何单票都不应重仓。
  按"最坏情况能否承受"倒推，而不是按预期收益倒推。
- **分散**：≥70% 档日均信号约 11 个，应分散到多个标的摊薄个股尾部风险。
- **不做 D1**：D1 净 +0.17% 扣掉滑点估计误差就归零，却要承担 -17% 尾部。

## 三、这个信号有多可信（八层检验）

| # | 检验 | 结果 | 通过 |
|---|---|---|---|
| 1 | 分档单调性 | 6 档完全单调（-1.84% → +3.56%）| ✅ |
| 2 | 混淆因素控制 | 控制当日涨幅后，每个分层内仍成立 | ✅ |
| 3 | 样本外持续性 | 秩相关 **+0.61**，TOP 席位样本外 +1.83%（基准 -0.26%）| ✅ |
| 4 | 置换检验 | **p = 0.0015**（2000 次置换）| ✅ |
| 5 | 逐月稳定性 | **9/9 个月为正**；对照组在零附近震荡 | ✅ |
| 6 | 滚动前向（不用平台指标）| 多空价差 +0.97% | ✅ |
| 7 | 诚实协议（前段选阈值）| 训练/留出两段一致 | ✅ |
| 8 | 过拟合校正 | **DSR 0.9757（通过）、PBO 0.0000** | ✅ |

### 诚实协议明细（前 70% 选阈值，后 30% 测量）

| 阈值 | 训练段 D5净 | **留出段 D5净** | 留出 n |
|---|---|---|---|
| ≥50 | -0.63% | +0.11% | 1,702 |
| **≥60** | +2.61% | **+3.15%** | 654 |
| ≥70 | +6.01% | **+4.95%** | 376 |
| ≥80 | +7.56% | **+5.95%** | 297 |

两段高度一致 → 阈值来自真实规律，不是数据窥探的产物。

### 过拟合校正

```
DSR = 0.9757   ->  通过（阈值 0.95）
  期望最大 Sharpe（纯选择偏差）SR0 = +0.8852
  实际最优 Sharpe                = +1.2869
PBO = 0.0000（252 个 CSCV 分割），样本外中位排名 1.000
```

**两个指标都指向"选择稳健"**：阈值越高收益越高是单调的，
所以样本内挑出的最优策略在样本外**仍排第一**。

> ⚠️ 但要如实说明两点：
> ① DSR 的分母按 9 次试验计算，若你实际还试了别的参数，试验数被低估；
> ② 该计算以 `d5_adj` 按周聚合，**存在重叠持仓与自相关**，
>    会系统性抬高 Sharpe 显著性，应看方向而非绝对数值。

## 四、每日操作流程

```bash
# 收盘后（龙虎榜约 17:30 披露，需稍等）
python3 run.py daily            # 已含龙虎榜采集
python3 run.py seat             # 跟随收益矩阵 + 席位排行
python3 run.py seat --follow --date 2026-09-29 --min-prob 60
```

`--follow` 输出**已按活跃度升序排列**（低频优先）：

| 代码 | 名称 | 席位胜率 | 席位活跃度 | 净买(万) | 席位 |
|---|---|---|---|---|---|
| 920298 | 腾信精密 | 80% ⭐ | 低频(0) | +835 | 中金财富杭州环球中心 |
| 600207 | 安彩高科 | 100% ⭐ | 低频(1) | +530 | 中泰证券总部 |
| 688244 | 永信至诚 | 60% | **高频**(13) | +1029 | 长城证券西北分公司 |

**筛选顺序：**

1. 席位胜率 ≥ 60（⭐ 表示 ≥70）
2. **去掉标记"高频"的**（过去 60 日上榜 ≥10 次）
3. **去掉涨停股**（默认已排除，含 ST 的 5% 与创业科创的 20%）
4. 优先净买入为正的

**持有**：目标 D5。**次日若一字涨停则放弃**（买不进，别追）。

## 五、必须知道的七个坑

1. **不要放宽门槛求数量**。50% 档看着"每天几百个信号"，实际净收益是负的。
   **信号少是特征，不是缺陷。**
2. **不要人为叠加其他过滤条件**。实测把"本地历史战绩为正"叠加上去，
   D1 净收益从 +3.16% **降到** +2.16%；三条件叠加变成 -0.10%。
   平台指标的信息量大于简单历史均值。**唯一验证有效的叠加是活跃度。**
3. **ST 股要单独处理**。主板 ST 涨跌停是 **±5%**（不是 9.5%），
   且 ST 的 D1 均值 **-1.38%**，差于非 ST 的 -0.10%。工具已自动处理。
4. **同一股票同日可能有多个上榜原因**（实测 13.4%）——直接 JOIN
   `billboard` 会让这些股票被重复计数，把 D1 从 +1.88% 拉偏到 +1.77%。
   工具已改用 `billboard_uniq` 去重视图。
5. **"自然人/机构/沪股通"不是席位**，是聚合标签，实测 D1 **-4%~-5%**、
   胜率 27%。工具已在排行与候选中排除。**散户扎堆上榜本身是强反向信号。**
6. **样本期只有 9 个月一轮行情**，虽逐月为正，未覆盖完整牛熊。
7. **核心发现无外部独立复现**。检索"龙虎榜 营业部 排名 样本外"零结果；
   平台字段名精确检索也零结果。**这是目前只有本地证据支撑的结论。**

## 六、可复现性

所有数字都可用以下命令自行复算（建议先跑自检）：

```bash
python3 tools/test_stats.py          # 14 项数值自检
python3 run.py seat                   # 阈值分档
python3 run.py seat --executable      # 剔除买不进的
python3 run.py seat --activity        # 活跃度维度
python3 run.py seat --honest          # 诚实协议
python3 run.py seat --overfit         # DSR + PBO
python3 run.py seat --validate        # 样本外持续性
python3 run.py seat --permute         # 置换检验（较慢）
python3 run.py seat --risk --min-prob 70   # 分布与尾部
```

## 七、一句话总结

> **跟"胜率 ≥60、且最近 60 个交易日不常上榜"的席位买入，
> 持有到第 5 天，分散、轻仓，次日一字板就放弃。**
>
> 这是统计优势，不是保证——胜率约 61% 意味着**三次里还有一次多是亏的**，
> 而最差的一笔可能是 **-96%**。
