# 研究笔记：指标、实证与局限

这份文档记录的是**这个工具自己跑出来的结论**，包括那些不成立的结论。
它不构成投资建议，也不承诺任何收益。

建议先读[局限与风险](#局限与风险)再决定要不要按这里的方法操作。

## 核心概念：为什么要看这些指标

短线（打板/接力）赚的是**情绪的钱**，不是公司的钱。所以判断的重点不是"这家公司好不好"，
而是"**现在市场上愿意接力的人多不多，他们赚不赚钱**"。

### 最重要的一个指标：昨日涨停溢价

```
prev_zt_premium = 昨天所有涨停股，今天的平均涨跌幅
```

这个数字直接度量**赚钱效应**：

- **为正**：昨天打板的人今天平均赚钱 → 接力意愿强 → 情绪升温
- **为负**：昨天打板的人今天平均亏钱 → 没人敢接力 → 情绪退潮

**涨停家数再多，如果昨日涨停今天全亏，那也是退潮。**
这是很多新手会误判的地方：只看涨停家数，以为"市场很热"。

### 指标体系

| 指标 | 含义 | 怎么用 |
|---|---|---|
| 涨停家数 | 市场做多意愿的广度 | 高但溢价为负 = 虚假繁荣 |
| 炸板家数 / 封板率 | 封板资金的质量 | 封板率跌破 62% 且高位 → 分歧 |
| 最高连板 | 情绪的高度（空间板） | 高度坍塌是退潮的强信号 |
| 连板家数 | 赚钱效应的持续性 | 连板家数骤减 = 接力链断裂 |
| 昨日涨停溢价 | **赚钱效应（核心）** | 转负 = 退潮 |
| 晋级率 | 昨涨停→今再涨停的比例 | 反映接力的成功率 |
| 跌停家数 | 亏钱效应的极端表现 | 骤增 = 恐慌 |

### 情绪周期阶段

工具把每天的指标合成一个 **0-100 的情绪温度分**，再叠加覆盖规则判断阶段：

```
冰点(0-22) → 修复(22-45) → 发酵(45-70) → 高潮(>70) → 退潮
                                    ↘ 分歧 ↗
```

覆盖规则（优先级高于分数）：

- **退潮**：昨日涨停溢价 ≤ -1.5%
- **分歧**：最高板 ≥ 4 板，但封板率 < 62%

判断阶段的目的是决定**仓位**，而不是决定买哪只：

| 阶段 | 通常的做法（参考，非建议） |
|---|---|
| 冰点 | 空仓或极轻仓等待，观察谁先起来 |
| 修复 | 试错仓，打第一个卡位的龙头 |
| 发酵 | 主升段，持有龙头，可加仓 |
| 高潮 | 减仓，不追高，准备离场 |
| 分歧 | 观察能否二次一致，谨慎 |
| 退潮 | **空仓**（最难也最值钱的操作） |

## 题材分析

### 新题材侦测

一个题材满足以下条件会被标为**新题材**：

- 今日有涨停，且此前 5 个交易日内没有出现过
- 今日涨停家数 ≥ 2

另有**异动启动**：老题材但家数从 ≤1 突然跳到 ≥3。

新题材是短线最值得关注的东西，因为新题材意味着**新的资金共识正在形成**，
而老题材通常已经过了最佳介入点。

每只股票还附带**催化原因原文**（来自同花顺对公开信息的汇总），
例如某只 4 板股的题材是"机器人轴承+汽车轴承+湖北国资"，催化是"柔性轴承试制完成、送样验证中"。
这让你不用自己去翻公告。

### 延续性评分（⚠️ 请看下面的实证结论，它不能预测延续）

题材延续性看起来是判断"能不能继续做"的关键，工具用 6 个分项加权评分（0-100）。
**但本节的检验表明这个评分预测不成立（见下方 ⚠️ 小节）**，请先读结论再决定是否使用：

| 分项 | 权重 | 含义 |
|---|---|---|
| breadth 广度 | 0.22 | 今日涨停家数（8 家以上满分） |
| trend 趋势 | 0.20 | 相对昨日是放大还是衰减 |
| leader 龙头 | 0.22 | 龙头的高度（4 板以上满分） |
| echelon 梯队 | 0.16 | 有几个高度层（有 1板/2板/3板 的完整梯队最好） |
| seal 封板质量 | 0.12 | 连板股占比 |
| sector 板块 | 0.08 | 板块指数表现 |

**梯队完整**比单纯家数多更重要：只有一堆首板没有连板，
说明资金只愿意做一天，不愿意接力。

#### ⚠️ 但是：这套评分的预测力经检验是**不成立的**

上面的权重是**手工设定**的，此前从未验证。补做检验后
（`./.venv/bin/python run.py theme-check`，2026-05-28 ~ 2026-09-30）：

**个股层面——这才是能不能赚钱的实质——完全没有预测力：**

| 口径 | 样本 | Spearman | 说明 |
|---|---|---|---|
| 全样本 | 6,131 | **-0.021** | 无预测力 |
| 训练段 | 4,257 | -0.016 | |
| **留出段** | 1,874 | **-0.029** | 样本外仍为负 |

**1 板股分层最能说明问题**（基准续板率 13.9%）：

| 评分 | 样本 | 次日续板率 |
|---|---|---|
| 0-49 | 711 | **18.4%** |
| 50-59 | 637 | 15.4% |
| 60-69 | 1,353 | **11.8%** |
| 70-100 | 1,866 | 13.2% |

**评分越高，续板率反而越低**（18.4% → 13.2%），控制连板高度后依然如此。

**题材层面只有微弱排序力，且不如直接看涨停家数：**

| 特征 | Spearman |
|---|---|
| 复合评分（6 项加权）| +0.055 |
| **仅"昨日涨停家数"**（`prev_zt`） | **+0.332**（是复合评分的 **6 倍**）|

> ⚠️ 别把三个数字混为一谈，它们的**标签和特征都不同**：
>
> | 特征 | 标签 | 相关 |
> |---|---|---|
> | 昨日家数 `prev_zt` | 未来 1~3 日是否还有涨停 | **+0.332** |
> | 当日家数 `zt_count` | 未来 1~3 日是否还有涨停 | +0.216 |
> | 当日家数 `zt_count` | 次日涨停家数（连续） | +0.278 |
> | 复合评分 | 未来 1~3 日是否还有涨停 | +0.055 |
>
> 看板②栏**按 `prev_zt` 排序**（唯一被 `validate_persistence_score`
> 验证过的那个），并用「有效 / 无效」直接标出哪列能用。

各分项单独表现暴露了问题所在：

| 分项 | Spearman | |
|---|---|---|
| echelon 梯队 | +0.154 | ✅ |
| breadth 广度 | +0.138 | ✅ |
| leader 龙头 | +0.122 | ✅ |
| seal 封板质量 | +0.067 | 弱 |
| **trend 趋势** | **-0.076** | ❌ **方向为负** |
| **sector 板块** | **-0.115** | ❌ **方向为负** |

**手工权重把有效信号稀释了，还混进了两个反向分项。**

#### 结论怎么用

- **不要把评分当作"延续性预测"**，它只是**题材热度的描述性指标**。
- 想知道延续性，**直接看涨停家数**（尤其是昨日家数）比看这个评分更准。
- 真正的可用信号在**席位跟随**（第五节），不在题材评分。
- 这个发现本身值得注意：**一个看起来合理的多因子加权，
  在验证前完全可能不如单一特征。**

### 龙头识别

- **题材内龙头**：连板高度优先，其次首封时间早，再次涨幅
- **全市场龙头**：按高度、首封时间、封单额排序

## 预测模块

预测的做法是**历史相似周期匹配**，刻意做得可解释：

1. 把每个交易日表示成一个 7 维特征向量
   （涨停家数、封板率、最高板、连板家数、昨涨停溢价、跌停家数、涨跌比）
2. z-score 标准化后，在历史中找与今天最相似的 K 天（默认 8 天）
3. 看这些日子**次日**实际发生了什么
4. 距离倒数加权平均，得到次日溢价与涨停家数的预测

输出：倾向（偏暖/中性/偏冷）、置信度、预测溢价、预测涨停家数、
以及相似样本中"次日赚钱比例"。

**每次预测都写入数据库**（`forecast_log`），事后自动回填实际值并统计方向命中率。
这是这个模块存在的意义：**让预测可以被证伪**。
运行 `./.venv/bin/python run.py forecast` 可以看到累计命中率。

> 说清楚一件事：这预测的是**情绪的方向**，不是某只股票的涨跌。
> 后者在这个框架里无法可靠预测，工具不会假装可以。

## 实证发现（用这个工具跑出来的真实结论）

这一节是**本工具最重要的产出**。用 2026-05-28 ~ 2026-09-30（88 个交易日）的
完整涨停板生态数据做检验，结果如下。

### 5.1 情绪周期确实存在，而且可以被量化

88 个交易日的阶段分布：

| 阶段 | 天数 |
|---|---|
| 发酵 | 28 |
| 高潮 | 21 |
| 修复 | 19 |
| 分歧 | 14 |
| 冰点 | 3 |
| 退潮 | 3 |

周期切换在数据上非常清晰。例如：

- `2026-07-13`：跌停 **109** 家，昨日涨停溢价 **-2.16%** → 判定**退潮**
- `2026-07-14`：溢价 **+7.08%** → 次日直接转为**高潮**
- `2026-08-19`：跌停 86 家，溢价 -1.87% → **退潮**
- `2026-08-21`：温度 21.8 → **冰点**

**结论：情绪周期作为"描述市场状态"的框架是有效的。**
它告诉你在周期的哪个位置，这件事本身有明确的信息量。

### 5.2 但是：次日情绪无法用这些指标预测

这是必须直说的一点。工具对 76 个交易日做了预测，并逐一回验：

| 指标 | 数值 | 含义 |
|---|---|---|
| 方向命中率 | 80.0% | 看起来很高 |
| **基准率** | **80.5%** | 历史上溢价为正的天数占比 |
| **相对优势** | **-0.5%** | **比"永远猜偏暖"还差** |
| 预测值与实际值相关系数 | **-0.207** | 负相关，即没有预测力 |
| 平均绝对误差 | 1.57 个百分点 | |

进一步做特征有效性检验：

| 今日特征 | 与次日溢价的相关系数 |
|---|---|
| 连板家数 | +0.160 |
| 温度 | +0.121 |
| 涨停家数 | +0.035 |
| 最高板 | -0.031 |
| 封板率 | +0.031 |


溢价自身的滞后自相关：**+0.138**（滞后1日）、+0.075（滞后2日）。

**结论：次日赚钱效应与今日各项情绪指标几乎不相关。**
换句话说，用"今天情绪如何"去推"明天赚不赚钱"，在本样本内**没有可靠信息量**。

唯一的例外仍然是冰点：温度 < 25 的日子里，次日溢价为正的比例只有 **57.1%**、
次日溢价均值仅 **+0.16%**（整体是 80.5% / +1.36%），样本 7 天。
这个方向符合直觉（冰点期风险明显更高），但样本太小，不足以当成信号。
其余三个阶段（修复/发酵/高潮）的次日胜率分别是 81.0% / 82.9% / 87.0%，
**区分度很低**。

### 5.3 这对"能不能学短线"意味着什么

1. **能学的是"识别状态"，不是"预测明天"。**
   情绪周期框架帮你判断现在处于哪个阶段（这个有信息量），
   但它不告诉你明天涨还是跌（这个没有信息量）。

2. **高命中率很容易是假象。** 本工具最初的预测命中率是 86.6%，
   看起来很棒——但基准率是 88.5%，模型实际上**没有超过"永远猜涨"**。
   任何声称"胜率 85%"的短线方法，都要先问：**基准率是多少？**

3. **周期定位的价值在风险控制，不在择时收益。**
   知道现在是退潮期，价值在于让你**减少出手**；
   这和"预测明天能赚多少"是完全不同的两件事。

4. **"买不进的收益"是本项目反复踩的同一个坑。**
   席位信号里买不进占 27.1%，龙头（5板）里买不进占 **37.7%**，
   而两者"看起来的收益"几乎都来自这些买不到的样本。
   **任何"次日买入"的短线结论，第一件事就是剔除次日涨停的样本。**
5. **"看起来合理"的多因子加权，验证前不要信。**
   本工具至少有两处犯过这个错：情绪预测（5.2）和题材延续性评分（5.3b）。
   两者都是"把几个直觉上相关的指标加权"，两者验证后都不成立，
   其中一个甚至不如单一特征。
   **如果你自己搭了一套评分，第一件事应该是像 `theme-check` 那样去验它。**

4. **这和"炒股养家"那套的差距在哪。**
   公开流传的心法是：判断周期位置 → 决定仓位 → 选龙头。
   本工具把前两步数据化了，也验证了第一步有效、第二步不可预测。
   第三步（选龙头）依赖的是**盘中实时信息、资金意图和盘感**，
   这些东西无法用日线级的历史数据回测出来——
   这也是为什么它难以被完整复制。

> 这段话不是要否定短线，而是想把"能学的部分"和"学不来的部分"分开。
> 把学不来的部分误当成能学的，是亏钱最快的路径。

### 5.3a 龙头（高连板）：看起来越高越强，其实赚的全是买不进的

这是"追龙头"直觉的直接检验（`./.venv/bin/python run.py leader-check`，6,507 个涨停事件）：

**第一层：原始收益确实随板数单调上升**

| 档位 | 样本 | 原始收益 | 控制 beta 后超额 |
|---|---|---|---|
| 1板 | 4,874 | +1.06% | +1.17% |
| 2板 | 999 | +2.23% | +2.18% |
| 3板 | 344 | +2.19% | +2.19% |
| 4板 | 143 | +2.54% | +2.57% |
| 5板 | 69 | **+3.50%** | **+3.53%** |

看起来完全符合"越高越强"，而且通过了 beta 控制与样本外分割
（训练价差 +1.49%、留出 +1.47%）。**但这是假象。**

**第二层：剔除"买不进"之后全部转负**

涨停股次日往往一字或大幅高开，**你买不到**：

| 档位 | 买不进占比 | 买不进者收益 | **可买者净超额** | 胜率 |
|---|---|---|---|---|
| 1板 | 13.7% | +10.48% | **-0.68%** | 41.5% |
| 2板 | 25.5% | +10.35% | **-0.94%** | 39.5% |
| 3板 | 30.8% | +10.29% | **-1.70%** | 33.6% |
| 4板 | 32.9% | +10.21% | **-1.50%** | 42.7% |
| ≥4板 | — | — | **-1.10%** | 43.8% |
| 5板 | **37.7%** | +10.00% | **-0.91%** | 39.5% |

**板数越高，"买不进"的比例越高（13.7% → 37.7%），
而那些买不进的恰恰贡献了约 +10% 的收益。**

样本外两段一致：≥4板可买净超额 **训练 -1.19%、留出 -0.96%**。

> **结论：追龙头不是一个正期望策略。**
> 它看起来赚钱，是因为统计里混入了你根本买不到的样本。
> 这条与席位信号是**同一类偏差**，但在龙头身上更严重——
> 席位买不进 27.1%，5 板龙头买不进 **37.7%**。

### 5.3b 题材延续性评分：又一个"看起来合理但验证不成立"的例子

详见第三节的 ⚠️ 小节。要点：

| 口径 | 结果 |
|---|---|
| 个股层面（次日是否续板）| Spearman **-0.021**（训练 -0.016 / 留出 -0.029）|
| 1 板股：评分 0-49 vs 70-100 | 续板率 **18.4% → 13.2%**（**反向**）|
| 题材层面：复合评分 | +0.055 |
| 题材层面：仅"昨日涨停家数" | **+0.332**（**6 倍**）|
| 分项 trend / sector | **-0.076 / -0.115**（方向为负）|

**手工设定的 6 项加权，不如一个单一特征，还混进了两个反向分项。**

这两个失败（5.2 情绪预测、5.3b 题材评分）指向同一个教训：
**在本样本内，凡是"用今天的横截面状态推明天"的尝试，都没有可靠信息量。**
唯一经得起检验的，是"跟着有历史战绩的席位买"（5.4）。

### 5.4 但是：席位数据是例外——它真的有效

上面说"次日不可预测"，指的是**情绪指标**。龙虎榜的**席位数据**是另一回事，
它经过样本外验证后**仍然有正优势**，这是本工具目前唯一站得住的信号。

数据依据：2026-01-05 ~ 2026-09-28，180 个交易日。
口径统一定义：**去重后**（`seat_buy_uniq` × `billboard_uniq`）、**已剔除聚合标签**、且次日收益非空的买方记录 = **46,923 条**。早期文档里的 57,991 / 68,355 / 7万 / 5.8万 是去重前后、是否含聚合、是否要求 d1 非空三种口径的混合值，现已统一。

**东财给每个席位-个股一个"3日胜率"（`RISE_PROBABILITY_3DAY`），它是真的：**

| 席位胜率档 | 样本 | 次日收益均值 | 次日为正 |
|---|---|---|---|
| < 35% | 13,992 | **-1.84%** | 37.2% |
| 35-40% | 6,125 | -0.46% | 44.4% |
| 40-45% | 15,249 | +0.27% | 48.0% |
| 45-50% | 8,669 | +0.45% | 49.3% |
| 50-60% | 8,443 | +1.21% | 54.1% |
| **≥ 60%** | **5,513** | **+3.56%** | **67.1%** |

相关系数 **+0.187**，分档**完全单调**。而且这不是"高胜率席位恰好买了强势股"——
控制当日涨幅后，在**每一个涨幅分层内部**效果都成立
（涨停层：胜率<40% 为 +0.29%，胜率≥50% 为 +3.18%）。

**剔除大盘后才能看清真相——"上榜=利空"只对低胜率席位成立：**

| 席位胜率档 | 样本 | D1 超额 | **D5 超额** | D10 超额 |
|---|---|---|---|---|
| < 40% | 20,238 | -1.34% | **-4.21%** | -5.59% |
| 40-50% | 24,022 | +0.35% | -0.96% | -2.07% |
| 50-60% | 8,464 | +1.20% | +0.68% | -1.02% |
| **≥ 60%** | 5,542 | **+3.51%** | **+6.70%** | **+5.88%** |

（超额 = 个股收益 − 同期上证涨幅。不做这个减法会得出错误结论：
全样本上榜股 D5 绝对收益 -1.24%，看起来"上榜就是利空"，
但同期大盘也跌 -0.13%，且高胜率组实际是 **+6.70%**。）

**两个关键点：**

1. **龙虎榜不能整体看多或看空，必须看"是谁在买"。**
   低胜率席位（大多是散户扎堆的营业部）上榜后 D5 超额 **-4.21%**；
   高胜率席位是 **+6.70%**。整体平均接近零，完全掩盖了这两极。
2. **高胜率席位的优势不衰减，D5 达峰。**
   这与"一日游"脉冲完全不同——说明跟的是中期逻辑，可持有数日。

**更关键的是它通过了样本外检验：**

| 组别 | 样本内 | **样本外** |
|---|---|---|
| TOP 10% 席位 | +4.27%（胜率 69.4%）| **+1.85%（胜率 55.8%）** |
| BOTTOM 10% 席位 | -2.71%（胜率 34.1%）| **-1.93%（胜率 38.1%）** |
| 全体基准 | — | -0.26%（胜率 45.8%） |

席位排名的样本内 vs 样本外**秩相关 +0.40** —— 说明这是**真实的席位能力差异**，
不是 140 个席位里挑出来的噪声（对比：情绪指标的滞后自相关只有 +0.14）。

**实测有效的席位（本地样本 ≥20 次）**

| 席位 | 次数 | 次日均值 | 胜率 |
|---|---|---|---|
| 华源证券深圳分公司 | 52 | **+5.76%** | 75.0% |
| 国泰海通成都龙腾东路 | 49 | +4.32% | 75.5% |
| 长城证券西北分公司 | 69 | +5.31% | 58.0% |
| 中信建投杭州庆春路 | 73 | +3.56% | 64.4% |
| 长江证券上海分公司 | 57 | +3.56% | 70.2% |

**反向指标（跟了会亏）**

`招商证券上海牡丹江路`：-8.93%，胜率 26.0%。
另外东财把 `自然人` / `中小投资者` / `机构` / `沪股通` 这类**聚合标签**混在席位列表里，
它们的次日收益是 **-4% ~ -5%、胜率 27%** —— **散户扎堆上榜本身就是强反向信号**。
本工具在排行和报告里已自动排除这些标签。

**统计显著性（置换检验）**

光看秩相关 +0.40 还不够——122 个席位的排名在有限样本下本就会有非零相关。
对"各席位真实水平相同"这一零假设做 2000 次置换检验：

```
./.venv/bin/python run.py seat --permute
  观测秩相关 +0.4003
  p 值 0.0015  -> 显著
```

即只有 **0.15%** 的概率能靠随机噪声碰巧得到这么强的持续性。
**这是本工具唯一通过完整统计检验的信号**（对比：情绪指标的自相关仅 +0.14）。

**成本敏感性**

短线交易的真实成本会吃掉大部分弱信号。按往返 0.40%
（印花税+佣金+过户费 0.10%，双边滑点 0.30%）计算：

| 胜率档 | 毛收益 | **净收益** | 结论 |
|---|---|---|---|
| 40-45% | +0.27% | **-0.13%** | 由盈转亏 |
| 45-50% | +0.45% | +0.05% | 几乎打平 |
| 50-60% | +1.21% | +0.81% | 勉强为正 |
| **≥ 60%** | +3.56% | **+3.16%** | 有实际意义 |

**所以阈值必须定在 50% 以上**（本工具默认 `SEAT_MIN_REP_PROB = 50`）。
40-45% 档看起来"正收益"，扣成本后是亏的。

**五层验证：一个信号要经过多少关才算可信**

这是本工具对待所有结论的标准流程。席位信号是目前**唯一全部通过**的：

| # | 检验 | 结果 | 通过 |
|---|---|---|---|
| 1 | 分档单调性 | 6 档完全单调（-1.84% → +3.56%）| ✅ |
| 2 | 混淆因素控制 | 控制当日涨幅后，每个分层内仍成立 | ✅ |
| 3 | 样本外持续性 | 秩相关 +0.40，TOP 席位样本外 +1.85% | ✅ |
| 4 | 置换检验 | p = 0.0015（2000 次置换）| ✅ |
| 5 | 逐月稳定性 | **9/9 个月为正**；对照组在零附近震荡 | ✅ |

**置换检验**（`run.py seat --permute`）回答"122 个席位里挑最好的，
会不会只是运气"。零假设是"所有席位真实水平相同"，把每席位样本内外
均值随机交换 2000 次，只有 **0.15%** 能碰巧达到 +0.40 的秩相关。

**逐月稳定性**（`run.py seat --monthly`）排除"靠某一段行情"：

| 月份 | 样本 | D1 均值 | 胜率 | | 月份 | 样本 | D1 均值 | 胜率 |
|---|---|---|---|---|---|---|---|---|
| 2026-01 | 507 | +4.59% | 71.0% | | 2026-06 | 478 | +3.52% | 69.5% |
| 2026-02 | 230 | +4.61% | 80.4% | | 2026-07 | 358 | +5.33% | 74.0% |
| 2026-03 | 304 | +3.91% | 69.4% | | 2026-08 | 241 | +5.45% | 76.8% |
| 2026-04 | 476 | +4.85% | 74.8% | | 2026-09 | 198 | +2.77% | 65.7% |
| 2026-05 | 479 | +4.26% | 72.4% | | | | | |

**排除了前视偏差嫌疑**：阈值扫描显示收益随阈值单调上升（≥80% 时
D5 仍 +8.95%），这不寻常，所以专门查了三件事：

- `rep_prob` 与**当日涨幅**的相关仅 **+0.041** → 不是由当日涨跌反推的
- 同一席位同一天买多只股时，**43% 的情况 `rep_prob` 不同**
  → 它含个股维度信息，不是纯席位统计
- **独立验证**：完全不用 `rep_prob`，只用席位过去 60 天的真实战绩，
  跟随组 D1 +0.33% vs 不跟随组 -0.63%，**价差 +0.97%**
  → 席位身份本身携带信息，两套证据互相印证

**风险画像：均值会骗人，必须看中位数和尾部**

上表的"均值"是**毛收益**。真正决定能否活下来的是分布形状
（`run.py seat --risk`，口径：排除涨停、可执行）：

| 阈值 | 期 | 样本 | 均值 | **中位数** | 5% 分位 | **最差** | 胜率 |
|---|---|---|---|---|---|---|---|
| ≥50% | D1 | 4,589 | +0.73% | +0.42% | -9.98% | **-88.77%** | 52.2% |
| ≥50% | D10 | 4,302 | -0.09% | -2.77% | -28.10% | -97.05% | 43.9% |
| ≥50% | D20 | 4,112 | -3.41% | -8.15% | -38.72% | -97.49% | 34.7% |
| **≥70%** | **D1** | 1,295 | **+2.70%** | **+2.37%** | **-6.28%** | **-17.39%** | **64.7%** |
| ≥70% | D5 | 1,235 | +8.44% | +5.57% | -12.61% | -96.57% | 70.6% |
| ≥70% | D20 | 1,102 | +5.00% | **-0.95%** | -32.46% | -97.49% | 47.5% |

**三个必须看清的点：**

1. **50% 阈值只适合 D1。** 持有到 D10 均值转负、中位数 -2.77%，
   到 D20 中位数 **-8.15%**。放宽阈值 + 拉长持有 = 亏钱。
2. **≥70% 档的尾部风险好得多**：D1 最差 -17.39%，而 ≥50% 档是 **-88.77%**
   （那是踩到退市/连续跌停）。**风险差异比收益差异更重要。**
3. **D5 以上均值被少数暴涨股拉高**。≥70% 档 D20 均值 +5.00% 但中位数
   **-0.95%**——"典型的一笔是亏的，靠个别翻倍股拉平均"。
   这种分布下**重仓长持非常危险**，也解释了为什么短线必须快进快出。

**外部独立证据：哪些被印证，哪些有冲突**

联网调研检索了公开复现与学术文献。**必须如实区分**——不能只挑支持的：

✅ **被独立印证**
- **聚合标签必须剔除**：独立复现同样列出"自然人/中小投资者/机构/沪股通/
  交易单元"为非席位合成类别，判据是"同时出现在买卖两榜"——与本项目
  发现的 -4%~-5%、胜率 27% 完全对应。
- **成本量级 0.2-0.4%**：外部复现给 0.2-0.4%，本项目用 0.4%（上沿，偏保守）。
- **一字板买不进**：外部复现给"一字板 10cm 次日 +4.21%、20cm +8.75%，
  但成交发生在隔夜排队者之间，超额属于中签者而非追价者"——与本项目
  "24.1% 买不进、高估 2.91%" 是同一现象。
- **龙虎榜 T 日 17:30 后披露**：任何以 T 日收盘为入场价的回测都含前视偏差。

⚠️ **与公开结论冲突**（必须保留，不作裁决）
- 一份 169 个交易日的独立复现发现：**上榜次数越多，后续超额越差**
  （正超额席位占比从 <15 次档的 36.2% 单调降至 >150 次档的 11.6%）。
  这与本项目的"席位能力可持续（秩相关 +0.40）"存在张力。
  **可能的解释**：两者口径不同——它按"活跃度"排序（高频霸榜多是通道/量化
  资金），本项目按"平台胜率"排序。但这一矛盾**尚未解决**，不应忽视。
- 学术侧 2017 年对外经贸硕士论文："龙虎榜上榜事件不产生超额收益，
  反而产生负异常收益；仅净买入占比 >10% 的子集有正异常收益。"

❌ **未能外部证真**
- **本项目最核心的结论——席位能力样本外秩相关 +0.40——在公开文献与
  公开复现中找不到任何对应佐证**。检索"龙虎榜 营业部 排名 样本外"
  只返回数据页面与新闻稿，无任何时间序列持续性检验。
  这是方法学空白点，本项目的 +0.40 属目前唯一可得估计。
- 平台 `RISE_PROBABILITY_3DAY` 字段名精确检索**返回零结果**，
  官方页面仅说明它是"上榜后 N 天平均涨幅/上涨概率"，属**滚动事后描述统计**，
  未披露窗口长度、最小样本量、剔除规则，也未声明为样本外估计。

> 结论：本项目的方法学**并非全无根基**（多重检验、成本、可执行性都有外部
> 支撑），但**核心发现未被外部独立复现**。在使用时请把这一点计入不确定性。

### 5.5 第二个维度：席位活跃度（并且它解决了一个外部矛盾）

联网调研发现一份公开复现的结论与本节**看似冲突**：它发现
"上榜次数越多，后续超额越差"（正超额席位占比从 <15 次档 36.2% 单调降到
>150 次档 11.6%），而本节说"席位能力可持续"。

用本地数据分解后，**两者都对，只是条件不同**：

| 高胜率席位（rep_prob≥60）内部 | 事件 | D1 均值 | D5 均值 | 胜率 |
|---|---|---|---|---|
| 活跃度 1-15 次 | 3,099 | **+4.10%** | **+8.99%** | 70.6% |
| 活跃度 15-30 次 | 834 | +3.20% | +5.57% | 63.3% |
| 活跃度 30-120 次 | 1,161 | +2.90% | +3.56% | 63.7% |
| 活跃度 >120 次 | 419 | **+2.14%** | **+2.31%** | 57.8% |

**控制住 `rep_prob` 之后，活跃度确实是单调反向的。** 外部按活跃度排序
看到负相关（因为高频席位大多是低胜率），本节按 `rep_prob` 排序看到正相关
——两个维度**独立且可叠加**。

用**滚动窗口**（只看过去 60 个交易日，无未来信息）在可执行口径下实测：

| 组合 | 可买样本 | D1 净 | **D5 净** | 胜率 |
|---|---|---|---|---|
| 高胜率（基准）| 4,025 | +0.26% | +2.54% | 54.9% |
| **+ 低频（≤2 次）** | 1,899 | — | **+5.40%** | **60.8%** |
| + 中频（3-9 次）| 1,041 | -0.29% | +0.95% | 49.2% |
| + **高频（≥10 次）** | 616 | — | **-2.11%** | 48.2% |
| 非高胜率 | 37,337 | -2.46% | -5.03% | 36.1% |

**并且通过了诚实协议**（训练段选活跃度上限，留出段测量）：

| 上限 | 训练段 D5净 | **留出段 D5净** | 留出 n |
|---|---|---|---|
| ≤1 | — | **+5.95%** | — |
| ≤2 | +6.00% | +5.40% | 408 |
| 不限 | +2.79% | +3.22% | 801 |

**D5 净收益从 +2.71% 提升到 +5.40%，翻倍，且两段一致。**

> ⚠️ 但注意：这是**在样本期内**观察到的第二个维度。即使通过了留出检验，
> 每多叠加一个维度，过拟合风险就上升一层。已用 Deflated Sharpe / PBO
> 做过拟合校正，**DSR 0.9757 通过、PBO 0.0000 很稳健**——
> 两个指标结论相反，说明"档位单调"可信但"最高档最优"不可过度自信
> （详见局限第 9 条）。

**必须知道的局限性**

1. **龙虎榜是盘后披露的**，你只能**次日**买入。而上表中的"次日收益"是
   `上榜日收盘 → 次日收盘`，**包含了次日跳空**，那部分你吃不到。
   因此报告里的跟随候选**默认排除涨停股**（涨停股次日往往一字或大幅高开）。
2. **样本期只有 2026 年 1~9 月**，未覆盖完整牛熊。
3. `RISE_PROBABILITY_3DAY` 不是每个席位都有，缺失时无法评估。
4. 这是**统计优势，不是保证**。胜率 67% 意味着**三次里还有一次亏**。
5. **对成本高度敏感**：往返成本每增加 0.1%，净收益同幅下降。
   本工具的 0.40% 假设对高频短线偏乐观，实际券商佣金差异会显著影响结论。
6. 高胜率席位的 D5 超额达峰，但**样本期只有 9 个月**，
   虽逐月为正，仍未覆盖完整牛熊。
7. **不要人为叠加过滤条件**。实测把"本地历史为正"叠加到 `rep_prob>=60`
   上，D1 净收益从 +3.16% **降到** +2.16%，三条件叠加更是变成 -0.10%。
   平台指标的信息量大于简单历史均值，加过滤只会缩样本、引噪声。
8. **`rep_prob>=70` 的收益不衰减，这可能是真信号，也可能是数据商
   用了较长窗口的历史统计造成的乐观偏差**——目前无法完全排除。
9. **多重检验校正是"接近但未通过"，必须如实说明**。已实现
   Deflated Sharpe Ratio 与回测过拟合概率（PBO/CSCV），
   把"扫了 9 个阈值"视为 9 次尝试来校正选择偏差：

   ```
   ./.venv/bin/python run.py seat --overfit
     各策略 Sharpe: -0.29 ... +1.15（横截面标准差 0.53）
     期望最大 Sharpe（纯选择偏差）SR0 = +0.8036
     实际最优 Sharpe                = +1.1543（近似）
     DSR = 0.9757  ->  通过（阈值 0.95）
     PBO = 0.0000（252 个 CSCV 分割），样本外中位排名 1.000
   ```

   **两个指标给出相反信号**：DSR 说"最优策略的优势只比纯运气好一点点"，
   PBO 说"样本内挑出的最优策略在样本外仍排第一，选择非常稳健"。
   解释：阈值越高收益越高是**单调**的，所以挑哪个都不会挑错（PBO 低）；
   但"最高档比次高档好多少"确实在噪声范围内（DSR 未过）。

   ⚠️ 该计算以 `d5_adj` 按周聚合，**存在重叠持仓与自相关**，会系统性
   抬高 Sharpe 显著性，所以应看方向而非绝对数值。
   另：文献提示稳健性分数与前瞻表现可能无关（一项预注册测试得
   Spearman rho = 0.013，p = 0.40），**验证层本身也不是万能的**。
10. **核心发现未被外部独立复现**。检索"龙虎榜 营业部 排名 样本外"
    无任何对应研究；平台字段名精确检索返回零结果。
    本节结论目前只有本地证据支撑。

> 结论：情绪周期告诉你"现在处于什么状态"（有用，但不能预测明天）；
> 席位数据告诉你"谁在买、他历史战绩如何"（这个**能**带来正期望）。
> 前者是地图，后者是导航。

### 先跑自检（强烈建议）

统计设施本身也可能有 bug，所以有已知答案检验：

```bash
python3 tools/test_stats.py     # 14 项数值自检（PSR/DSR/PBO/正态函数）
python3 tools/validate_dim.py all   # 校验 heavy-research 维度报告契约
```

自检内容：纯噪声下 PSR 应服从 U(0,1)、DSR 应不显著、PBO 应≈0.5；
有一个明显更优策略时 PBO 应→0。**这些断言曾抓出我自己写错的测试期望**
（原以为单次 PSR 应≈0.5，实际它服从均匀分布）。

```bash
./.venv/bin/python run.py lhb --date 2026-09-29          # 采集某日龙虎榜
./.venv/bin/python run.py lhb --backfill --start 2026-01-01   # 回填历史
./.venv/bin/python run.py seat                            # 跟随收益矩阵 + 席位排行
./.venv/bin/python run.py seat --validate                 # 样本外持续性检验（最重要）
```

> 龙虎榜走的是 `datacenter-web.eastmoney.com`，与行情接口 `push2.eastmoney.com`
> **不同域**——前者实测**未被限流**，后者经常限流。这是席位数据能稳定回填的原因。
> 注意 `pageSize` 上限是 **500**（传 1000 会被静默截断为 500），
> 且 `result: null` 既表示空集也表示限流，代码里做了区分。

### 踩过的坑（都在代码注释里标了）

1. **东财 `date` 参数是假的**。给涨停池传历史日期，它会静默返回当天数据。
   所以历史回填必须走同花顺，否则会把今天的数据写到过去日期上造成污染。
2. **东财 clist 的 `pz` 上限是 100**，传 200 会被服务端直接断连。
3. **东财会限流**，返回 `{"rc":0,"data":null}` 而不是报错。必须把它当"重试"而非"无数据"。
4. **`Connection: close` 会大幅提高失败率**。改用 keep-alive 连接复用后，
   全市场 59 页的失败页从 ~15 页降到 0。
5. **日K的 `f58` 是振幅不是涨跌幅**，`f59` 才是。搞错会让所有涨幅数据失真。
6. **同花顺涨停池 `limit` 上限 200**，超过报错。
7. **同花顺 `high_days_value` 的编码是 `(板数 << 16) | 天数`**，
   与东财 `lbc`（连板数）交叉验证 19/20 一致。

龙虎榜/席位相关的坑：

8. **席位明细报表不含股票名称**。`RPT_BILLBOARD_DAILYDETAILSBUY` 的字段里
   只有 `SECURITY_CODE`/`SECUCODE`，没有 `SECURITY_NAME_ABBR`。
   早期代码读这个字段拿到全 `None`，导致报告里股票名显示为 `—`。
   现在由 `_backfill_names()` 从 `billboard` 自动回填。
9. **`pageSize` 上限是 500**。传 1000 会被服务端静默截断为 500 而不报错，
   分页时若不按实际返回数推进就会漏数据。
10. **`result: null` 既表示"空集"也表示"被限流"**，两者无法从响应区分。
    代码里对"当天（尚未披露）返回空"与"限流"分别处理。
11. **涨停判定必须按板块**。主板 9.5%、创业板/科创板 19.5%、北交所 29%，
    另有 ST 股 5%。早期 `follow_signals` 硬编码 `pct >= 9.5`，
    会把科创板 +9.5% 的**非涨停**股票误当成涨停而排除。
    现已复用 `collect._limit_threshold()`。
12. **同一股票同日可能有多个上榜原因**（实测 **13.4%** 的
    `(trade_date, code)` 有多行，因为 `billboard` 主键含 `reason`）。
    直接 JOIN 会让这些股票被重复计数，实测把可执行样本的
    D1 从 +1.880% 拉偏到 +1.768%。现提供 `billboard_uniq` /
    `seat_buy_uniq` 两个去重视图，所有统计都走视图。
13. **ST 股的涨跌停不是板块标准值**。主板 ST 是 **±5%**，
    创业板/科创板 ST 仍是 ±20%，北交所 ST 仍是 ±30%。
    早期代码对 ST 一律按板块标准值处理，导致主板 ST 的 +5% 涨停
    被判为"未涨停"而混入"可执行"样本——而 ST 的 D1 均值 **-1.38%**，
    显著差于非 ST 的 -0.10%，属实质性污染。
    经验验证：ST 记录的涨幅峰值在 5.0%（主板）与 20.0%（创业科创）。
    现已由 `_limit_threshold(code, is_st=...)` 与 `seat._thr()` 处理。
14. **`机构专用` 曾经不在聚合标签里**——它是本地数据中**出现最多**的
    聚合标签（6,400 次），却漏在 `AGGREGATE_LABELS` 之外，泄漏进了
    报告 9.2 的净买入排行。同时 `follow_signals` **完全不做聚合过滤**，
    导致 9.1"跟随候选"与 9.2"排除聚合"两节口径相反：
    **最该被排除的（聚合席位是强反向指标）反而没被排除在跟随候选之外。**
    实测全库 180 个交易日共 **256 条**聚合记录会混入候选，现已 0 条。
15. **ST 判定曾在 3 个函数中恒失效**——`_thr` 依赖 `"ST" in name`，
    但 `risk_profile` / `executable_estimate` / `threshold_sweep` 的
    SELECT 不含 `s.name`，`r.get("name")` 恒为 None，于是 ST 股按 9.5%
    而非 4.8% 判"未涨停"，**把买不进的真涨停 ST 股放进了可执行样本**。
    而这三个函数正是产出"可执行口径"结论的地方，失效方向是让收益偏乐观。
    修复后"买不进"占比从 23.7% 升到 **27.1%**。
16. **配置项"看似生效实则只是文案"**——`seat.py` 原本用自己的字面量
    `DEFAULT_DAYS=180` / `MIN_SEAT_TRADES=20`，与 `config` 里的值
    **恰好相等因而掩盖了断链**。改 `config.SEAT_MIN_TRADES` 后，
    `run.py` 的表头文案会跟着变，**但筛选逻辑不变**。
    现已改为从 config 读取，单一来源。
17. **`run.py lhb --backfill` 必崩**——`lhb.backfill` 调用
    `trading_days(conn, start, end)`（3 个位置参数），而签名是
    `(end=None, count=30)`，抛 `TypeError`。
    **这解释了为何席位数据一直靠 `tools/` 离线导入。** 已修复。
18. **`run.py seat` 空库必崩**——`following_edge` 无数据时返回 `[]`，
    而 `run.py` 用 `if r[0]:` 解包，抛 `IndexError`。已改为给出提示。
19. **`cmd_status` 遗漏全部 3 张龙虎榜表**——用户看不到席位数据覆盖情况，
    而席位恰恰是唯一验证有效的信号。已补。
20. **`billboard` 主键含 `reason`，而 SQL 中 NULL≠NULL**——
    `ON CONFLICT(trade_date,code,reason)` 对 `reason IS NULL` **永不触发**，
    连续 upsert 会不断插入新行。当前实际数据 0% 为 NULL（未触发），
    属**潜在**风险。，同一席位同一天可能同时出现在买卖两侧，
    查询时必须指定 `side` 否则会重复计数（报告里曾出现同一只股票两行）。

## 局限与风险（请认真读）

1. **工具不替你决策**。它整理数据、计算指标、给出统计参考，
   但买卖是你的决定，盈亏也是你的。
2. **历史相似不等于未来重演**。预测模块输出的是"情绪处于类似位置时历史上通常怎么走"，
   样本量小（几十到一两百天），且市场结构在变。
3. **A股短线生态已经和十年前不同**。量化资金占比大幅提升，
   打板/接力的结构性胜率下降。即使完全复制某个游资前辈的方法，
   在今天的市场里也未必有当时的赔率。
4. **幸存者偏差**。成名的游资是幸存者，用同样方法爆仓的人不会出名。
   把成功者当唯一样本会严重高估胜率。
5. **数据可能有误**。第三方公开接口，存在延迟、缺失、口径差异。
   跌停家数在历史回填时是**近似值**（按板块阈值推算，未剔除 ST）。
6. **短线是负和游戏**。扣掉手续费和冲击成本，多数参与者长期亏损。
